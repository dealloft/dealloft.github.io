Dealloft site
- Blog posts and deals both live in data.js. Open it in any text editor.
- Copy a post block in POSTS to add a post. Copy a deal block in DEALS to add a deal.
- Set SHOW_SAMPLES = false when you have real content.
- Set your email in contact.html (search your-email@gmail.com).
- Rename: find-replace Dealloft in the .html files and in data.js (SITE_NAME).
